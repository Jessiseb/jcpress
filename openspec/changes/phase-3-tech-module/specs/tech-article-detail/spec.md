# Spec Delta

## Purpose

技术分享的文章详情页：让访客从首页或列表点进来后，以**适合长文阅读**的版式读到 Markdown 原文，并能顺着相邻篇继续读下去。

## ADDED Requirements

### Requirement: 详情页只暴露已发布内容

详情接口 SHALL 只返回已发布（`status=1`）的文章；草稿与归档 SHALL NOT 通过任何公开路径取到正文。详情响应 SHALL 包含 Markdown 原文、标题、分类、标签、发布日期、字数派生的阅读时长与浏览量，并 SHALL **内联上一篇与下一篇**（同类型、按发布时间相邻，不存在时为 `null`），使前端一次请求即可完成渲染。文章 ID SHALL 以字符串下发。

#### Scenario: 打开已发布的文章

- **WHEN** 访客请求一个已发布文章的 slug
- **THEN** 响应包含 Markdown 原文、分类、标签、阅读时长与浏览量
- **AND** 响应包含 `prev` 与 `next` 两个字段（不存在相邻篇时为 `null`）

#### Scenario: 草稿不可达

- **WHEN** 访客请求一个 `status=0` 的文章 slug
- **THEN** 返回不存在（业务码 40401，HTTP 404）
- **AND** 响应中不含该文章的正文或标题

#### Scenario: ID 以字符串下发

- **WHEN** 检查详情响应中的文章 ID
- **THEN** 它是字符串而不是数字（避免 JavaScript 大整数精度丢失）

### Requirement: 护眼阅读版式

详情页正文 SHALL 满足以下可判定档位：字号 `17px`、行高 `1.9`、正文栏宽 `68ch`（实测换算后落在 60–72 个字符宽之间）、段间距不小于 `1.15em` 且段首不缩进。代码块 SHALL 使用 `14px`、行高 `1.7`、等宽字体并横向滚动（SHALL NOT 因长行换行或溢出页面）。正文与代码块的文本颜色 SHALL 在亮暗两种主题下都满足 WCAG AA 对比度。

#### Scenario: 正文档位

- **WHEN** 测量正文段落的计算字号、行高与容器宽度
- **THEN** 字号为 17px、行高为字号的 1.9 倍、容器宽度落在 60–72ch

#### Scenario: 代码块不撑破版面

- **WHEN** 渲染一个含超长行的代码块
- **THEN** 代码块内部横向滚动，页面本身不出现横向溢出

### Requirement: 章节自动编号与标题锚点

正文中的二级标题 SHALL 由样式自动编号（`01`、`02` …，编号不写进 Markdown 源），且每个二三级标题 SHALL 有一个稳定的锚点 id；页面 SHALL NOT 依赖作者手写编号。

#### Scenario: 二级标题自动编号

- **WHEN** 检查正文中二级标题的前置伪元素内容
- **THEN** 它是按出现顺序递增的两位数字

#### Scenario: 标题锚点可定位

- **WHEN** 访问某个标题的锚点链接
- **THEN** 页面滚动到该标题，且该标题元素的 id 与链接一致

### Requirement: 目录与滚动联动

详情页 SHALL 提供由正文二三级标题生成的目录；目录项的锚点 SHALL 与正文标题的 id **完全一致**。视口宽度 `≥1024px` 时目录 SHALL 常驻在正文侧栏；`<1024px` 时 SHALL 折叠为可展开形式，SHALL NOT 占据正文首屏。

#### Scenario: 目录锚点全部命中

- **WHEN** 遍历目录中的每个锚点链接
- **THEN** 页面上都存在 id 与之一致的标题元素

#### Scenario: 窄屏折叠

- **WHEN** 在 375px 宽度下打开详情页
- **THEN** 目录不再是常驻侧栏，而是默认收起的可展开区域

### Requirement: 浏览量幂等上报

详情页 SHALL 在打开后上报一次浏览量；同一访客（按 IP 与 User-Agent 指纹）在同一自然日内对同一篇文章的重复访问 SHALL 只计一次。上报失败 SHALL NOT 影响正文阅读，也 SHALL NOT 把页面变成错误态。

#### Scenario: 同日重复访问只计一次

- **WHEN** 同一指纹在同一天内两次打开同一篇文章
- **THEN** 该文章的浏览量只增加 1

#### Scenario: 上报失败不影响阅读

- **WHEN** 浏览量接口返回错误
- **THEN** 正文仍然完整渲染，页面不显示错误态
