# Proposal: phase-2-r2

## Why

二期上线后用户实测提出 5 条反馈。逐条归因后，**其中两条是实现缺陷，三条是设计不足**：

| 反馈 | 归因 |
| --- | --- |
| 背景流线太多、白天形态看着眼花 | **实现缺陷（几何错误）**：`preserveAspectRatio="none"` 把 SVG 拉伸（x 1.84× / y 2.02×），而线宽是以 viewBox 为单位给的，`strokeWidth: 1.55` 实际渲染成 **≈2.9px 粗线**；再叠加 72 条与 0.5 的不透明度上限，白天就是满屏灰带 |
| 字看不清 | **实现缺陷（取色失误）**：流线用 `#0f172a` 压到 0.5 透明度后呈**中灰**，与技术栈条目名用的 `--ds-c-text-mute`（80% 灰）**明度几乎相同** —— 不是"背景纹理压字"，而是"同色干扰" |
| 缺滑动闪出感（也不用很重） | 设计不足：入场只有「淡入 + 上移 18px」，偏保守 |
| 实习 / 项目经历放到技术栈前面 | 设计不足：原顺序把「能力清单」排在「经历」之前，与"30 秒内看懂做过什么"的阅读逻辑相反 |
| 技术栈 / 联系我 / 获奖经历排版普通 | 设计不足：三块都停在"能读"的规格表层面，缺版式主角 |

## What Changes

- **流线剂量（BREAKING：数值上限收紧）**：路径数 **72 → 48 / 32 / 16**（桌面 / 平板 / 手机）；线宽改用 `vector-effect="non-scaling-stroke"` 固定在 **0.6–1.1px**（不再被拉伸放大）；线色改**品牌蓝**；单条描边不透明度上限 **0.5 → 0.28**。
- **正文色调分层**：正文主色 `#3c3c43` → **近黑**，`--ds-c-text-mute` / `--ds-c-text-subtle` 各提一档；正文与流线彻底分族（字是黑的主体、线是蓝的淡纹）。
- **入场（闪出）**：位移 18 → **28px** + 极轻放大（0.985 → 1），时长 460 → 520ms；只动 `transform` / `opacity`（不动布局属性，避免重蹈性能覆辙）；JS 门控与 reduced-motion 降级不变。
- **区块顺序**：改为 **首屏 → 关键数字 → 实习经历 → 项目经历 → 技术栈 → 教育与荣誉 → 联系我**（经历类排在能力清单类之前），大小节节奏跟着重排。
- **三块版式重做**（都不新增卡片、不新增颜色语义、不恢复点阵/进度条）：
  - **技术栈**：三列规格表 → **能力带**（组名进固定左栏作版式锚点，技能以流式词组排右栏，档位是名字旁的极小文字标记）；
  - **获奖经历**：年份小字 → **年份轴**（年份用展示衬线、明显大于奖项名，纵向对齐成可扫读的时间轴）；
  - **联系我**：两栏定义列表 → **一个主角 + 次级入口**（邮箱以展示字号作为主入口且可点击发信，其余入口降为次级条目）。

## Capabilities

### New Capabilities

（无。反馈全部落在既有的图案 / 排版 / 首页结构三条能力域内。）

### Modified Capabilities

- `visual-language`：**图案分为布景层与标记层**（新增线宽 / 剂量 / 路径数 / 线色四条量化上限）；新增**布景层与正文的色调分离**（明度差 + 最坏情况合成对比度两条可计算判据）。**首屏体积与资源预算**里的手机档路径数同步收紧。
- `homepage`：新增**区块顺序**；**技术栈的分组与档位**（补「组名作左栏锚点 + 技能流式排布」）；**教育与荣誉**（补「年份轴」）；**联系方式与隐私**（补「邮箱为主入口」）。

## Impact

- **样式令牌**：`frontend/src/styles/theme.jcpress.css`（`--ds-flow-line` 改品牌蓝、`--ds-flow-alpha-max` 0.28、正文三档灰阶加深）。
- **组件**：`components/visual/FlowField.tsx`（路径分档 48/32/16、`non-scaling-stroke`、线宽档、透明度档）；`components/home/{SkillMatrix,EducationAwards,ContactBar}.tsx` + 各自 module.css（三块重做）；`pages/home/HomePage.tsx`（顺序）+ 六个区块的 `data-rhythm`。
- **全局样式**：`global.css` 的入场参数。
- **验收**：`audit-behavior.cjs`（路径数断言 72/48/24 → 48/32/16；新增线宽、剂量、色调分离、区块顺序、三块版式断言）；`audit-contrast.cjs` 必跑；`docs/phase2-effect-matrix.md` 追加本轮条目。
- **文档**：`docs/dev-journal.md`（阶段 26+）、`docs/decisions.md`（线宽几何错误与取色失误两条教训）。
- **流程偏差（用户决定）**：本轮用户选择「**先做出来看效果再说**」，因此**跳过了计划评审 gate**，proposal / design / specs / tasks 与实现同批产出，评审改在看图之后。
