# Proposal: phase-2-r3

## Why

二期 r2 上线后，用户分批提出反馈。逐条归因，**只有一条是新增能力，其余全是设计不足或决策反转**：

| 反馈 | 归因 |
| --- | --- |
| 实习经历想要「左图 + 右文」的特写，不要三段并列 | 设计不足：原先是「三段各自一张卡」的列表，没有主次，也没有「一眼看完一段」的落点 |
| 获奖经历要做成版本时间线（左年份 / 竖轴圆点 / 右名称+等级） | 设计不足：r2 的「年份轴」只把年份排进左栏，没有轴线，读起来仍是一列标签 |
| 想要参照组件那种「滚动时球在视口里滑动」的效果 | **新增能力**：本站第一个**分节停靠**的常驻装饰层 |
| 白天要地球、夜间要月球 | **新增能力**：两颗**不同**的天体，不是同一张贴图换两种颜色 |
| 技术栈「乱乱的 → 效果不行 → 都不行」；联系我「太端正」「不要有背景是方块的」 | 设计不足，且**归因错了两轮**：技术栈换了 **5 版**、联系我换了 **2 版** 才收敛（过程与分析见 `design.md`） |
| 「联系我的 QQ 邮箱换成手机号」 | **决策反转**：`decisions.md` #3「手机号默认不上站」被用户明确推翻 |

## What Changes

- **天体布景层（新增）**：与流线层同层的全屏固定装饰（`position: fixed` + `z-index: -1` + `aria-hidden` + `pointer-events: none`）。**亮色是地球、暗色是月球**，两张**自托管**的等距圆柱贴图（地球用公有领域的 NASA Blue Marble；月球由 `scripts/gen-moon-texture.cjs` 确定性生成，LCG seed `20260930`，可复现）。球体观感**忠实移植**参照组件的六条 `box-shadow`（改成 `em` 基准，base = 直径），而不是用渐变近似 —— 它因此不占用任何渐变宿主名额。
- **分节停靠（新增）**：滚动时天体在视口内的**位置 / 尺寸 / 不透明度**三者都随当前区块变（7 个停靠点），由 1400ms 的 `translate` / `scale` / `opacity` 过渡负责「滑」。三者都是合成器属性。判定当前区块用 `IntersectionObserver` + **视口中线一条 10% 窄带**，不新增滚动监听。
- **实习经历 → 整幅特写 + 切换器**：从「三段并列」改成「一次一段」——切换条（tab / 左右箭头 / 圆点，均 ≥44px 命中区）+ 一张公司图 + 正文。新增 `data-full`（**唯一**允许正文顶格到第 1 列的例外），因为收在 8 列里时右栏只剩 514px、正文被挤成 1038px 高。
- **获奖经历 → 版本时间线**：左侧粗体年份 + 灰色等级，圆点落在竖轴上，右侧奖项名；竖轴按行绘制（首行从圆点起、末行到圆点止）。
- **技术栈 → 玻璃面板 + 分类色胶囊**：复用全局 `.panel`（与关键数字 / 项目经历同一套令牌）；**分类给色相、档位给填充深浅**（两个维度走两个正交通道），六个方向色相进调色板（`--ds-hue-1..6`，避开状态色绿/黄/红）；因「深浅」不能自明，面板顶部**必须**有一行三档图例。
- **联系我 → 手机号为主入口 + 号码左置**：`tel:`（E.164）取代 `mailto:` 成为主入口，展示为 3-4-4 分组；版式撤掉全部方块背景与发丝线，**标签内联写在值前面、不设固定列宽**（固定列宽会把所有值推到同一条竖线上，那正是「表单」观感的来源）。
- **面板适用范围 2 → 3 类区块**：加入技术栈。判定按 `data-glass` 标记。
- **隐私护栏收窄**：`profile.test.ts` 从「全站不许出现 11 位手机号」改为「手机号只许出现在 `contacts` 里，且必须是 `tel:` 链接」—— 防的是**意外泄露**，不是**有意公开**。
- **验收工具**：`audit-behavior.cjs` 47 → **71 项**（新增天体、停靠、贴图登记、面板范围等断言，并改写技术栈与联系我两条）；`audit-perf.cjs` 写进**使用边界**（A 档噪声，见 design.md）；`shot-final.cjs` 的滚动循环改成逐帧让帧（否则 `IntersectionObserver` 采不到样）。

## Capabilities

### New Capabilities

（无新增能力域。天体落在 `visual-language` 既有的「图案分为布景层与标记层」之下 —— 它被定义为**标记层的 3D 形态**，而不是第三类纹理。）

### Modified Capabilities

- `visual-language`：
  - **首屏体积与资源预算**：新增「每一张图片都必须挂在显式登记的宿主上（内容图 `data-photo` / 天体贴图 `data-celestial`）」，且**天体贴图必须是同源路径**，任何远程贴图判违规。
  - **图案分为布景层与标记层**：把天体定义为标记层的 3D 形态（圆形裁剪窗口 + 等距圆柱贴图 + 球体明暗）；新增**自转**与**分节停靠**；明确它**不叠加**视差位移；规定停靠点的两条几何约束（首屏落在正文右侧空白、每个停靠点完整落在视口内且无横向溢出）；首屏以外的停靠点收剂量（不透明度 ≤0.3）；规定亮暗是两颗不同天体且可见性互补。
- `homepage`：
  - **技术栈的分组与档位**：改为「玻璃面板里的分类色胶囊云」，明确两个维度走两个通道（色相 = 分类、填充深浅 = 档位），并把图例定为硬要求。
  - **实习经历的整幅特写与切换**（新增 requirement）：整幅特写通栏、正文恰好两块、带面恰好一块、切换控件暴露全部经历。
  - **教育与荣誉**：奖项改为时间线（年份 + 竖轴圆点 + 名称与等级）。
  - **联系方式与隐私**：手机取代邮箱成为主入口（`tel:`、≥2 倍字号）；新增三条**可判定的形式约束**（禁止方块背景、禁止条目间发丝线、标签不得占固定列宽）；手机号只许出现在 `contacts`。
  - **重点区块的面板化**：两类区块 → 三类（加入技术栈），并写明技术栈入选的理由。

## Impact

- **新增文件**：`components/visual/CelestialField.{tsx,module.css}`、`hooks/useActiveScene.ts`、`public/textures/{earth-blue-marble,moon-surface}.jpg`、`scripts/gen-moon-texture.cjs`（新增 npm script `textures:moon`）、`design-system/{hero-backdrop,landing-scroll,skill-layout,contact-layout}-options.html`（候选预览，不入构建产物）。
- **组件**：`App.tsx`（挂载天体层，首页路由限定）；`components/home/{ExperienceTimeline,EducationAwards,SkillMatrix,ContactBar,Hero}.tsx` + 各自 module.css。
- **样式**：`theme.jcpress.css`（`--ds-body-*` 天体令牌 12 项 × 2 主题、`--ds-hue-1..6` × 2 主题）；`global.css`（`.section[data-full]` 例外）。
- **数据**：`data/profile.ts`（`contacts` 的邮箱条目 → 手机条目）；`data/profile.test.ts`（护栏收窄为三条断言）。
- **新增依赖**：`lucide-react`（**唯一**一个）。**拒绝**引入 Tailwind / shadcn / framer-motion / next —— 参照组件是 Next.js + framer-motion + Tailwind 的玻璃卡片，本轮只取它的两个想法（芯片化、指针聚光），其余按本站既有令牌与 CSS Modules 重做（见 design.md D3）。
- **验收**：`audit-behavior.cjs` 71 项、`audit-contrast.cjs` 亮暗各 220 处 0 未达标、`shot-final.cjs` 四视口无溢出、`vitest` 26 通过。
- **文档**：`docs/decisions.md` #81–#98（含两条测量纪律、四条过程教训）；`docs/dev-journal.md` 阶段 29+。
- **流程偏差（用户决定）**：与 r2 相同 —— 用户选择「**先做出来看效果再说**」，跳过计划评审 gate，proposal / design / specs / tasks 与实现同批产出。技术栈与联系我两处因用户多次否决而**多轮返工**，返工过程完整记录在 design.md，不静默丢弃。
