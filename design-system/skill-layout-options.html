技术栈排版候选 · 第二轮

前四个候选（大胶囊 / 紧凑胶囊 / 对齐网格 / 组名在上）你都否了。这一轮换两个**根本不同的方向**， 不用「芯片云」这条思路：把档位从「标签」变成「列」（结构），或者把分类从「文字」变成「颜色」。 同样用你真实的数据与令牌，正文区按线上实际的 828px。

① 深度矩阵档位变成列

行 = 六个方向，列 = 熟悉 / 掌握 / 了解。档位不再是贴在每项后面的小字，而是它所在的列 —— 于是「Java 熟悉、Golang 了解」这件事从「读一个词」变成「看它站在哪一列」。顺带得到一个以前读不出来的信息： 前端那一行**整行都在「掌握」列**，一眼就知道我不是前端方向的人。空单元格留白，本身就是信息。

② 紧凑芯片 · 每个方向一个色分类变成颜色

保留「方向左栏 + 右侧标签云」，但给**六个方向各一个色相**：组的颜色由组名旁那枚圆点定， 组内的芯片吃同一个色相（深浅只由档位决定）。颜色在这里是**语义**（哪一项属于哪个方向），不是装饰 —— 参照组件里我没取的就是这个「彩色圆点」，它确实有用。没有绿色的色相。

③ 深度矩阵 + 分类色两个方向合体

①的结构，加上②的分类色点（只有组名旁边一枚小圆点，单元格本身保持文字色）—— 结构给出档位，颜色给出方向，两者都不靠额外文字。

④ 玻璃面板 + 分类色胶囊放开面板限制

这就是参照组件的路子，按本站令牌重做：一层玻璃面板把这一节收成一个「设计过的组件」， 组内胶囊带分类色、深浅由档位决定。两处必须一起放开：① spec 现在写着「面板只出现在关键数字与项目经历 两类区块」（有断言守着）；② 分类色相进调色板。如果「好看」指的是这个，那就是这两条要改。
