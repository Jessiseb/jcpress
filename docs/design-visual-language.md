## 1. 目标与验收

### 1.1 目标

一期页面目前是「干净但扁平」：纯色平铺 + 发丝线分块，信息清楚，没有质地。本次修订要给它**味道**——用一套图案母题把页面从「内容平铺」变成「有景深的剧场」，同时**不牺牲简历可读性**。

一句话判据：陌生人打开首页，第一眼觉得这站有设计；HR 往下读，仍然读得顺畅。

### 1.2 验收标准

| 编号 | 判据 | 取证方式 |
| --- | --- | --- |
| A | 亮/暗两套主题 × 四档宽度（375 / 390 / 768 / 1280）逐页无横向滚动、无重叠 | 浏览器断言套件（`.tmp/tools/audit-behavior.cjs`）+ 截图 |
| B | 行为断言 13 项保持全绿，并新增「技术分享」列表页断言（计数取自 `articles.length`、空态渲染、无死链） | 同上（**不走 vitest**，见 §10.1） |
| C | 图案带来的新增网络请求 = **0**；首屏 JS gzip 仍 ≤ 200KB（规划 §2.8） | 零请求：网络面板人工核对；体积：构建恢复后补测（见 §10.1） |
| D | 所有新增前景/背景组合的对比度**实测并写进注释**；`prefers-reduced-motion` 下动效全降级；hover 不是任何信息的唯一入口 | `.tmp/tools/audit-contrast.cjs` + 键盘走查 |

## 2. 设计语言：环是母题

参照站的图案不是底纹，是**同心圆环 + 中心聚光 + 遮罩渐隐**组成的「光场」。本站把它提炼成母题「环」，固定出现在 4 处 —— 图案因此成为系统，而不是随机点缀。

| 位置 | 形态 | 尺寸与剂量 |
| --- | --- | --- |
| 顶栏 logo | 4 圈同心环标记（替代现在的实色方块 —— 上一轮已从渐变改为 `--ds-c-accent-bg` 实色） | 18px；不透明度 45%，颜色随 `--ds-c-accent` |
| 首屏 Hero | 大环 + 蓝色聚光 + 晕影 | 容器约 1000×1000px，居中偏上 45% |
| 项目经历区块标题右侧 | 中环 badge | 54px，周期同 `--ds-ring-period`，不透明度 65% |
| 页脚 | 大环（下半场布景） | 约 820×820px，整体不透明度 75% |

**明确不做**：环的漂移 / 旋转 / 呼吸循环（用户已否决 R3 方案的连页漂移）。环是静止的布景，只随首屏一起淡入一次。

### 2.1 环的配方（照参照站实测，数值按本站正文密度下调）

```css
background:
  radial-gradient(circle at 50% 45%, var(--ds-glow), transparent 34%),
  repeating-radial-gradient(circle at 50% 45%, var(--ds-ring) 0 1px, transparent 1px var(--ds-ring-period)),
  linear-gradient(135deg, var(--ds-c-bg) 15%, var(--ds-c-bg-elv) 50%, var(--ds-c-bg) 85%);
mask-image: radial-gradient(#000 5%, transparent 72%);
```

| 令牌 | 亮色（C 装置版） | 暗色（A 剧场版） | 依据 |
| --- | --- | --- | --- |
| `--ds-glow` | `rgb(10 123 245 / 10%)` | `rgb(59 130 246 / 20%)` | 参照站聚光 `#fff3`（20%）；亮底上必须减半，否则糊 |
| `--ds-ring` | `rgb(9 111 220 / 6%)` | `rgb(255 255 255 / 8%)` | 参照站 `#ffffff1f`（12%）；本站正文比参照站密，降到 8%。亮色初定 4%，实测白底上几乎不可见，校准到 6% |
| `--ds-ring-period` | `46px` | `46px` | **2026-09-28 校准结果**，见下 |

**校准结果（2026-09-28 实测，替换原「7 → 24 → 46」待定规则）**：
用 `.tmp/tools/probe-ring.cjs` 把周期分别设成 9 / 24 / 46px，在同一区域 1:1 截图对比（暗色下最明显）：

- **9px**（＝参照站源值）与像素网格打架，暗色下出现**间距不均的摩尔纹** —— 左侧弧宽、中心弧密，不是同心环；
- **24px** 已经均匀，但仍偏「纹理」；
- **46px** 是均匀可辨的同心环，最接近用户在参照站上看到并认可的观感。

结论：**取 46px**，两个主题一致。理由记录：参照站源值 7px 在它自己的页面上同样是摩尔纹，
用户认可的其实是「宽而匀的同心环」这个**观感**，不是那个会与像素网格打架的数字。
亮色环不透明度同步从 4% 校准到 6%（4% 在白底上几乎看不见）。

> **实现注记（层 3 不用作叠加层）**：配方里的第三层 `linear-gradient(135deg, …)` 在参照站是**元素自身的底**（那个元素就是首屏背景）。本站的环是**叠在正文之下的装饰层**，若照搬这一层会得到一块不透明底、把 body 的氛围层与正文全遮住。因此：环组件只取**第 1、2 层 + 遮罩**（透明背景）；「底面差」由既有的 `--ds-atmosphere-*` 氛围层承担。这条差异是刻意的，不是遗漏。

> 暗色的弱化文字与强调色在上一轮已按对比度校正过（`decisions.md` #12 / #13），本次**只改底色、面、发丝线与玻璃层**，不去动那两个已经实测达标的档位。
> 发丝线从实色 `#e2e2e3` 改成半透明，理由：环装置会铺在区块之下，实色线会把图案「切断」，半透明线才能让环透过线继续读得到；改动后需在 1280 / 375 两档目视确认线没有消失。

**对比度纪律**（沿用 `theme.jcpress.css` 现有做法）：下列组合必须在实现时用 WCAG 公式实算并把实测值写进注释，任何一项不达标就调到达标为止：

1. 暗色 `--ds-c-accent-text`(#fff) 压在 `--ds-c-accent-bg`(#096fdc) 上 —— 旧底实测 4.86:1；新底更暗，比值只会更高，复测确认即可
2. 暗色 `--ds-c-accent`(#4d9bff) 作正文色压在**新底** `#08090c` 上 —— 旧底 `#1b1b1f` 实测 6.10:1，新底复测
3. 暗色 `--ds-c-text-mute` / `--ds-c-text-subtle` 压在 `#08090c` 上 —— 旧底实测 8.01:1 / 5.95:1，新底复测
4. 亮色 `--ds-c-hairline`（12% 黑）与白底 —— 仅需「可见」，不适用文本门槛，但需在 1280 与 375 两档目视确认不消失
5. **环与聚光叠加后的最大局部亮度** —— 必须确认压在环最亮处的正文仍达标（这是本次唯一新增的对比度风险点）
6. 暗色 `--ds-atmosphere-2`（紫 `rgb(144 35 246 / 7%)`）与新的蓝环聚光叠加 —— 目视确认不过曝、不出现第三色相；必要时降到 5%

## 4. 排版规则

| 项 | 现值 | 新值 |
| --- | --- | --- |
| 展示字字重（H1/H2/H3） | `--ds-fw-bold` 700 | **500**（`--ds-fw-display`） |
| Hero 字号 | 3.6rem / 57.6px | **4.25rem / 68px**（响应式阶梯 68 → 44 → 40 → 34px） |
| 区块标题 | 1.65rem / 26.4px | **1.875rem / 30px** |
| 展示字字距 | `-0.01em` | **`-0.02em`** |
| 数字（关键数字、统计） | 无衬线 | **衬线 + `font-variant-numeric: tabular-nums`** |

响应式阶梯（沿用基线四档断点 419 / 719 / 959 / 1440）：
Hero `68 → 44 (≤959) → 40 (≤719) → 34px (≤419)`；区块标题 `30 → 24px (≤719)`。

### 4.1 斜体只给 Latin

**中文永远是正体。** 中文没有真斜体，浏览器会做机械倾斜，在中文字形上非常廉价。允许出现 `font-style: italic` 的位置**仅限**：

1. Hero 的 `h1` 第二行是定位行 `AI 应用开发工程师`（**不加斜体** —— `AI` 只有两个字母，斜体后读起来像 `/\I`）；
2. 斜体落在紧跟其后的 headline 段落里的英文词：`Agent`、`Java`；
3. 项目名中的 Latin 词（`AIWorker`、`Pulse`）。

同时该词降到 `--ds-c-text-mute`（参照站的手法：斜体 + 降灰同时出现）。**禁止**给整句中文、给标题、给按钮添加斜体。

### 4.2 等宽字白名单

`--ds-font-mono` 只允许用在：表格表头、年份、技能档位、数字单位、阅读时长、文章计数。**禁止新增英文全大写 eyebrow 标签**（`MISSION` / `SELECTED WORKS` 那类）——frontend-design 明列其为生成感信号；现有 Hero 的 kicker（`广州 · AI 应用开发`）保持原样不动。

### 5.1 项目经历表格的交互（可访问性硬约束）

- 表格行是一个 `<button aria-expanded>`，**点击/回车展开**该项目的摘要与亮点。

- ≤719px：表格降级为卡片堆叠，展开交互保持一致。
- 理由：上一轮 code review 已立规「hover 不作唯一入口」；触摸设备没有 hover。

## 7. 新内容页骨架：「技术分享」列表页

### 7.1 数据结构（先行前端常量，结构对齐后端 VO）

新增 `frontend/src/data/articles.ts`：

```ts
export interface ArticleVO {
  slug: string            // 对齐后端 article.slug
  title: string
  summary: string         // ≤ 120 字
  category: string        // 对齐 category.name
  tags: string[]          // 对齐 tag.name
  publishedAt: string     // YYYY-MM-DD
  readingMinutes: number
}
```

- 后端映射：`article`（`type = TECH`）+ `category` + `tag`（规划 §6.3、§4.2）。
- 组件只认 `useArticles()` hook；后端就绪后只换 hook 实现（与 `useProfile()` 同款策略）。
- **不含**：正文、浏览量、分页、搜索、详情页（均属 M3，本次不做）。

### 7.2 页面结构

```
技术分享（衬线 30px）
一句定位（§6 表格里的那句）
共 5 篇 · 更新至 2026-05        ← 等宽字；计数一律取自 articles.length
────────────────────────────────
日期        标题                              分类      阅读
2026-05-12  ThreadLocal 在 Tool 层的上下文隔离   AI·Agent  8 分钟
...

[ 空态 ] 列表为空时：说明接口未接通 + 引导回首页
```

**计数口径**：`共 N 篇` 的 N 恒为 `articles.length`，**不写死 17**。简历上的「CSDN 17 篇」是真实总量，等 M3 接通真实数据后自然会对上；当前示例数据是 5 条，页面就显示 5 篇。更新日期取列表内最大 `publishedAt`，空列表时不渲染该行。

- 列表项**不设链接**（详情页未建，避免死链）。
- 复用首页的发丝线与半透明边，不新造一套视觉。

## 9. 可访问性红线

1. 正文对比度按 §3 逐项实算并注释。
2. `prefers-reduced-motion: reduce` 下：环仍显示（静态），入场与 hover 过渡全部降为 0.001ms（现有全局规则覆盖）。
3. hover 不是任何信息的唯一入口（§5.1）。
4. 触摸目标 ≥ 44px（现有 `min-height: 44px` 约定保持）。
5. 焦点可见：`:focus-visible` 轮廓保持，玻璃面板上需确认轮廓对比度不消失。
6. 环与聚光是 `pointer-events: none` 的装饰层，不进无障碍树（用伪元素或 `aria-hidden`）。

## 11. 与既有决策的冲突与修订

设计不是从零开始，本次与三条既有结论冲突，在此显式记录（同步写入 `docs/decisions.md`）：

**① 「不加噪点颗粒」作废。**
`theme.jcpress.css` 现有注释写着「只用径向渐变网格这一种技法，不加噪点颗粒 —— 克制方向下叠纹理是反向操作」。
本次用户明确要「补图案」，图案成为母题，该条**作废**；注释同步改写为「图案统一走环装置，不得引入第二种纹理（噪点/网格/斜纹）」，以免变成叠纹理。

**② 大数字统计区的折中。**
`style-ref-golangstar.md` §7 反模式表列了「大数字 count-up 统计条」，上一轮据此删掉了仪表盘式数字区。
参照站的数字区是蓝色衬线大字。折中：**保留现有编辑式行结构，只把数值换成蓝色衬线 + 22px**，不恢复四格大数字卡片、不恢复 count-up。用户已确认。

**③ 环与 7px 周期不是照抄截图。**
参照站实际周期是 7px，但截图缩放会产生摩尔纹（看起来是十几圈大环）。本次按 §2.1 的校准规则用真实渲染判定，而非按截图观感照抄。

**④ 提前落地 M3 的列表页外壳。**
`/tech` 从占位页升级为列表页外壳，属规划 §13 的 M3 范围（M3 还包含接口、详情、Markdown 渲染、浏览量）。本次只做**前端外壳 + 常量数据**，不含后端与详情页。用户已确认此范围扩大。
